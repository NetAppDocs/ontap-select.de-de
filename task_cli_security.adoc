= Sichere ONTAP Select-Implementierung
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Eine ONTAP Select Implementierung kann abgesichert werden, indem bei Bedarf das Kennwort für das Administrator-Konto der Deploy-virtuellen Maschine über die Befehlszeile geändert wird.

.Schritte
. Melden Sie sich über das Administratorkonto bei der CLI des Bereitstellungsdienstprogramms an.
. Ändern Sie das Passwort:
`password modify`
. Beantworten Sie alle Fragen, die Ihnen für Ihre Umgebung angemessen sind.

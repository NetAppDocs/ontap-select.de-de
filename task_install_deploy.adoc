= Installieren Sie ONTAP Select Deploy
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Sie müssen das ONTAP Select Deploy-Administrationsprogramm installieren und das Dienstprogramm zum Erstellen eines ONTAP Select-Clusters verwenden.

.Bevor Sie beginnen
Sie haben die Checkliste vor der Installation für Ihren Hypervisor-Host geprüft:

* link:esxi-host-configuration-and-preparation-checklist.html["Checkliste für ESXi-Hosts"]
* link:hyper-v-host-configuration-and-preparation-checklist.html["Hyper-V Host Checkliste"]
* link:kvm-host-configuration-and-preparation-checklist.html["Checkliste für KVM-Hosts"]




[[step-1-download-the-virtual-machine-image]]
== Schritt 1: Laden Sie das Image der virtuellen Maschine herunter.

Laden Sie das ONTAP Select Paket von der NetApp Supportseite herunter.

.Bevor Sie beginnen
https://mysupport.netapp.com/site/user/registration["Sie verfügen über ein registriertes NetApp Support Site Konto"^].

.Über diese Aufgabe
Das ONTAP Select Deploy Verwaltungsprogramm ist als virtuelle Maschine (VM) verpackt und basiert auf dem Open Virtualization Format. Die einzelne komprimierte Datei hat das Suffix `ova` für ESXi Hosts, `vhdx.tgz` für Hyper-V und `raw.tgz` für KVM Hosts. Die VM stellt den Deploy Server und Installationsabbilder für ONTAP Select Knoten bereit.

.Schritte
. Rufen Sie die link:https://mysupport.netapp.com/site/downloads/["NetApp Support Site Downloads"^] Seite auf.
. Scrollen Sie nach unten und wählen Sie *ONTAP Select Deploy* aus.
. Wählen Sie die gewünschte ONTAP Select Version aus.
. Lesen Sie die Endbenutzer-Lizenzvereinbarung (EULA), und wählen Sie *Accept & Continue* aus.
. Wählen Sie das passende *ONTAP Select Deploy Install*-Paket aus und laden Sie es herunter. Beantworten Sie alle erforderlichen Eingabeaufforderungen.




[[step-2-verify-the-ontap-select-deploy-ova-signature]]
== Schritt 2: Überprüfen Sie die ONTAP Select Deploy OVA-Signatur.

Überprüfen Sie die ONTAP Select Open Virtualization Appliance (OVA)-Signatur, bevor Sie das Installationspaket installieren.

.Bevor Sie beginnen
Überprüfen Sie, ob Ihr System die folgenden Anforderungen erfüllt:

* OpenSSL-Versionen 1.0.2 bis 3.0 zur grundlegenden Überprüfung
* Öffentlicher Internetzugang für die Online Certificate Status Protocol (OCSP)-Überprüfung


.Schritte
. Laden Sie die folgenden Dateien von der Produkt-Downloadseite auf der NetApp Support-Website herunter:
+
[cols="2*"]
|===
| Datei | Beschreibung 


| `ONTAP-Select-Deploy-Production.pub` | Der öffentliche Schlüssel, der zur Überprüfung der Signatur verwendet wird. 


| `csc-prod-chain-ONTAP-Select-Deploy.pem` | Die Vertrauenskette der öffentlichen Zertifizierungsstelle. 


| `csc-prod-ONTAP-Select-Deploy.pem` | Das Zertifikat, mit dem der Schlüssel generiert wird. 


| `ONTAPdeploy.ova` | Die ausführbare Produktinstallation für ONTAP Select. 


| `ONTAPdeploy.ova.sig` | Der SHA-256-Algorithmus wird gehasht und dann vom Remote Support Agent (RSA) unter Verwendung des signiert `csc-prod` Schlüssel und Signatur für den Installer. 
|===
. Überprüfen Sie das `ONTAPdeploy.ova.sig` Datei verwendet die zugehörigen Zertifikate und Validierungsbefehle.
. Überprüfen Sie die Signatur:
+
[source, cli]
----
openssl dgst  -sha256 -verify ONTAP-Select-Deploy-Production.pub -signature ONTAPdeploy.ova.sig  ONTAPdeploy.ova
----




[[step-3-deploy-the-virtual-machine]]
== Schritt 3: Virtuelle Maschine bereitstellen

Die Erstellung der virtuellen Maschine ONTAP Select Deploy erfolgt auf Ihrem Hypervisor-Host.

[role="tabbed-block"]
====
.ESXi
--
Die ONTAP Select Deploy VM wird mithilfe des OVF VM Image auf einem ESXi Host installiert und gestartet. Im Rahmen der Installation wird die Netzwerkschnittstelle für die Verwendung von DHCP oder einer statischen IP Konfiguration konfiguriert.

.Bevor Sie beginnen
Für einen ESXi-Hypervisor müssen Sie die Bereitstellung der ONTAP Select Deploy VM vorbereiten:

* Aktivieren Sie die OVF-Funktion in Ihrem Browser, indem Sie das VMware Client Integration Plugin installieren oder eine ähnliche Konfiguration nach Bedarf durchführen
* Aktivieren Sie DHCP in der VMware-Umgebung, wenn Sie der Bereitstellungs-VM dynamisch eine IP-Adresse zuweisen


Sie benötigen die Konfigurationsinformationen, die bei der Erstellung der VM verwendet werden, einschließlich des VM-Namens, des externen Netzwerks und des Hostnamens. Bei der Definition einer statischen Netzwerkkonfiguration benötigen Sie zusätzlich folgende Informationen:

* IP-Adresse der bereitzustellenden VM
* Netzmaske
* IP-Adresse des Gateways (Router)
* IP-Adresse des primären DNS-Servers
* IP-Adresse des zweiten DNS-Servers
* DNS-Suchdomänen


.Über diese Aufgabe
Wenn Sie vSphere verwenden, enthält der Assistent zur Bereitstellung der OVF-Vorlage ein Formular, das alle Informationen zur Bereitstellungskonfiguration einschließlich der Netzwerkkonfiguration enthält. Wenn Sie dieses Formular jedoch nicht verwenden, können Sie stattdessen mithilfe der Konsole der Bereitstellungs-VM das Netzwerk konfigurieren.

.Schritte
. Greifen Sie auf den vSphere-Client zu und melden Sie sich an.
. Navigieren Sie zum entsprechenden Speicherort in der Hierarchie, und wählen Sie *OVF-Vorlage bereitstellen* aus.
. Wählen Sie die OVA-Datei aus und schließen Sie den Assistenten zum Bereitstellen der OVF-Vorlage ab. Wählen Sie die für Ihre Umgebung geeigneten Optionen aus.
+
Sie müssen das Passwort für das Administratorkonto definieren. Sie müssen dieses Passwort angeben, wenn Sie sich beim Dienstprogramm Deploy anmelden.

. Wählen Sie nach Bereitstellung der VM die neue VM aus. Wenn die Software aufgrund Ihrer Angaben zum Implementierungsassistenten noch nicht eingeschaltet ist, schalten Sie sie manuell ein.
. Falls erforderlich, können Sie das Bereitstellungsnetzwerk über die VM-Konsole konfigurieren:
+
.. Wählen Sie die Registerkarte *Console*, um auf die ESXi-Host-Setup-Shell zuzugreifen und den Einschaltvorgang zu überwachen.
.. Warten Sie auf die folgende Eingabeaufforderung:
+
Hostname:

.. Geben Sie den Hostnamen ein und wählen Sie *Enter*.
.. Warten Sie auf die folgende Eingabeaufforderung:
+
Geben Sie dem Admin-Benutzer ein Passwort ein:

.. Geben Sie das Passwort ein und wählen Sie *Enter*.
.. Warten Sie auf die folgende Eingabeaufforderung:
+
DHCP zum Festlegen von Netzwerkinformationen verwenden? [n]:

.. Geben Sie *n* ein, um eine statische IP-Konfiguration zu definieren, oder *y*, um DHCP zu verwenden, und wählen Sie *Enter*.
.. Wenn Sie eine statische Konfiguration wählen, geben Sie alle erforderlichen Netzwerkkonfigurationsinformationen an.




--
.Hyper-V
--
Die Installation und der Start der ONTAP Select Deploy VM auf einem Hyper-V-Host erfolgen mithilfe des Assistenten für neue virtuelle Maschinen.

.Bevor Sie beginnen
Voraussetzung ist, dass der Hyper-V-Host die folgenden Anforderungen erfüllt:

[cols="1,2"]
|===
| Anforderung | Wert 


| Hyper-V Rolle | Installiert, einschließlich des Hyper-V PowerShell Moduls 


| VM-Generation | Generation 1 


| vCPUs | 2 


| Erinnerung | 4GB, statisch (dynamischer Speicher deaktiviert) 


| Bootdisk | An IDE Controller 0, Position 0 angeschlossen 


| Freier Speicherplatz | Mindestens 40 GB auf dem Volume, auf dem die VM-Festplatte gespeichert ist 


| Archivierungstool | tar, enthalten in Windows Server 2019 und höher 
|===
Voraussetzung ist, dass Ihnen die folgenden Informationen vorliegen:

[cols="1,2"]
|===
| Informationen | Beschreibung 


| VM-Name | Name der Deploy VM, z. B. ONTAP-deploy-HV 


| Name des virtuellen Switches | Name des externen virtuellen Switches, z. B. ONTAP_Vswitch 


| Name der physischen Netzwerkkarte | Host Netzwerkadapter, der mit dem Deploy VM Netzwerk verbunden ist 


| VLAN-ID | Nur erforderlich, wenn der Upstream-Switch-Port getaggten Datenverkehr erwartet 


| Host-Name | FQDN oder kurzer Hostname der Deploy VM 


| Administratorpasswort | Passwort für das Administratorkonto, das beim ersten Start festgelegt wurde 
|===
Bei der Definition einer statischen Netzwerkkonfiguration benötigen Sie die folgenden zusätzlichen Informationen:

* IP-Adresse der bereitzustellenden VM
* Netzmaske
* IP-Adresse des Gateways (Router)
* IP-Adresse des primären DNS-Servers
* IP-Adresse des zweiten DNS-Servers
* DNS-Suchdomänen


.Über diese Aufgabe
Das Erstellen eines externen virtuellen Switches unterbricht kurzzeitig den Netzwerkverkehr auf der physischen Netzwerkkarte. Falls Sie über die physische Netzwerkkarte remote mit dem Host verbunden sind, ist eine Out-of-Band-Managementplattform (z. B. die Server BMC) oder ein anderer Netzwerkadapter erforderlich, damit der Zugriff nicht verloren geht.

.Schritte
. Im Hyper-V Manager öffnet *New* > *Virtual Machine* den New Virtual Machine Wizard.
. *Weiter* auswählen.
. Nach Eingabe des VM-Namens erfolgt die Auswahl von *Weiter*.
. Zuerst erfolgt die Auswahl von *Generation 1*, anschließend von *Weiter*.
+

NOTE: ONTAP Select mit Hyper-V unterstützt keine VMs der 2. Generation.

. Die Menge des Arbeitsspeichers wird eingegeben, anschließend wird *Weiter* ausgewählt.
+

NOTE: Die Mindestanforderung an den Arbeitsspeicher beträgt 4GB.

. Den virtuellen Switch in der Dropdown-Liste auswählen und anschließend *Weiter* wählen.
. Nach der Auswahl von *Eine vorhandene virtuelle Festplatte verwenden* > *Durchsuchen* ist die `vhdx.tgz`Image-Datei zu suchen und auszuwählen.
. *Weiter* auswählen.
. Nach der Überprüfung der Konfiguration wählen Sie *Fertigstellen* aus.
. Falls erforderlich, können Sie das Bereitstellungsnetzwerk über die VM-Konsole konfigurieren:
+
.. Warten Sie auf die folgende Eingabeaufforderung:
+
[listing]
----
Host name :
----
.. Geben Sie den Hostnamen ein und wählen Sie *Enter*.
.. Warten Sie auf die folgende Eingabeaufforderung:
+
[listing]
----
Use DHCP to set networking information? [n]:
----
.. Geben Sie *n* ein, um eine statische IP-Konfiguration zu definieren, oder *y*, um DHCP zu verwenden, und wählen Sie *Enter*.
.. Wenn Sie eine statische Konfiguration auswählen, geben Sie bei Bedarf alle Informationen zur Netzwerkkonfiguration ein.




--
.KVM
--
Die ONTAP Select Deploy VM wird auf einem KVM Host mithilfe des OVF VM Image installiert und gestartet. Im Rahmen der Installation wird die Netzwerkschnittstelle für die Verwendung von DHCP oder einer statischen IP Konfiguration konfiguriert.

.Bevor Sie beginnen
Sie benötigen die Konfigurationsinformationen, die bei der Erstellung der VM verwendet werden, einschließlich des VM-Namens, des externen Netzwerks und des Hostnamens. Bei der Definition einer statischen Netzwerkkonfiguration benötigen Sie zusätzlich folgende Informationen:

* IP-Adresse der bereitzustellenden VM
* Netzmaske
* IP-Adresse des Gateways (Router)
* IP-Adresse des primären DNS-Servers
* IP-Adresse des zweiten DNS-Servers
* DNS-Suchdomänen


.Schritte
. Melden Sie sich bei der CLI auf dem Linux-Server an:
+
[listing]
----
ssh root@<ip_address>
----
. Erstellen Sie ein neues Verzeichnis und extrahieren Sie das RAW-VM-Image:
+
[listing]
----
mkdir /home/select_deploy25
cd /home/select_deploy25
mv /root/<file_name> .
tar -xzvf <file_name>
----
. Erstellen und starten Sie die KVM-VM mit dem Dienstprogramm „Deploy Administration“:
+
[listing]
----
virt-install --name=select-deploy --vcpus=2 --ram=4096 --os-variant=debian10 --controller=scsi,model=virtio-scsi --disk path=/home/deploy/ONTAPdeploy.raw,device=disk,bus=scsi,format=raw --network "type=bridge,source=ontap-br,model=virtio,virtualport_type=openvswitch" --console=pty --import --noautoconsole
----
. Falls erforderlich, können Sie das Bereitstellungsnetzwerk über die VM-Konsole konfigurieren:
+
.. Stellen Sie eine Verbindung zur VM-Konsole her:
+
[listing]
----
virsh console <vm_name>
----
.. Warten Sie auf die folgende Eingabeaufforderung:
+
[listing]
----
Host name :
----
.. Geben Sie den Hostnamen ein und wählen Sie *Enter*.
.. Warten Sie auf die folgende Eingabeaufforderung:
+
[listing]
----
Use DHCP to set networking information? [n]:
----
.. Geben Sie *n* ein, um eine statische IP-Konfiguration zu definieren, oder *y*, um DHCP zu verwenden, und wählen Sie *Enter*.
.. Wenn Sie eine statische Konfiguration auswählen, geben Sie bei Bedarf alle Informationen zur Netzwerkkonfiguration ein.

[[step-4-sign-in-to-the-deploy-web-interface]]
== Schritt 4: Sign in bei der Deploy-Weboberfläche an.

Sign in zur Web-Benutzeroberfläche, um zu bestätigen, dass das Deploy-Dienstprogramm verfügbar ist, und führen Sie die Erstkonfiguration durch.

.Schritte
. Rufen Sie im Browser das Dienstprogramm Deploy unter Verwendung der IP-Adresse oder des Domain-Namens auf:
+
`\https://<IP_address>/`

. Geben Sie den Administrator-Kontonamen und das Kennwort ein, und melden Sie sich an.
. Wenn das Popup-Fenster *Willkommen bei ONTAP Select* angezeigt wird, überprüfen Sie die Voraussetzungen und wählen Sie *OK*, um fortzufahren.
. Wenn Sie sich zum ersten Mal anmelden und die Bereitstellung nicht mit dem in vCenter verfügbaren Assistenten installiert haben, geben Sie bei der entsprechenden Aufforderung die folgenden Konfigurationsdaten an:
+
** Neues Kennwort für das Administratorkonto (erforderlich)
** AutoSupport (optional)
** VCenter Server mit Account-Anmeldedaten (optional)
